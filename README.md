# Number System Converter

A simple Python program that converts numbers between different number systems.

## Features

* Decimal to Binary
* Decimal to Octal
* Decimal to Hexadecimal
* Binary to Decimal
* Octal to Decimal
* Hexadecimal to Decimal
* Handles invalid binary, octal, and hexadecimal inputs
* Menu-based interface

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed.
2. Run the program using:

```bash
python number_system_converter.py
```

3. Select an option from the menu and enter the required number.
